# Code Comments Style
- Comments only where code needs clarification — never narration.
- Limit comments to 80 character max summaries.
- Do not pad. No summary is fine if the source-code item is obvious.
- Short sentences. Use RFC 2119 keywords for obligations.
# Github rules 
- Do NOT ever put your self as a contributor
- keep commit messages extremely short and consice
- commit mesages should never ever be paragraphs except in the most rare cases
# Context
- keep in mind i am writing this software for a small hobby team so all these admin/legal/security/licensing concerns are of no value or importance.
